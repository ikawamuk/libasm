# libasm

## Description
A 42 project that reimplements basic C standard library functions in
x86-64 assembly using NASM. Includes string manipulation, input/output,
and additional functions for linked lists and base conversion.

## Instructions
Requires Linux x86-64, NASM, Clang, and make.

```sh
make        # Build libasm.a, including bonus functions
make test   # Run tests
make fclean # Remove generated files
```
